It ingests messy CSV data, validates it against configurable rules, and provides real-time data health visibility. ## 🏗️ Architecture Flow ```mermaid graph LR A[📁 CSV Upload] --> B{⚡ FastAPI Gateway}; B --> C[🛡️ Bronze Layer]; C --> D[⚙️ YAML Quality Engine]; D --> E{📊 Quality Report}; E --> F[📈 Streamlit Dashboard]; ``` ## ✨ Key Features - 📥 **Auto-Ingestion**: REST API triggers pipeline on upload. - ⚙️ **Configurable Rules**: Edit `quality_rules.yaml` without touching Python. - 📊 **Observability Dashboard**: Live error/warning visualizations. - 🛡️ **Immutability**: Raw data is timestamped and never overwritten. ## 🚀 Quick Start ```bash git clone https://github.com/vishnucharankolla2/medlearn-data-hub.git cd medlearn-data-hub python3 -m venv venv source venv/bin/activate pip install -r requirements.txt python3 src/generate_dirty_data.py python3 src/run_quality_checks.py streamlit run dashboard/app.py ``` ## 📈 Quality Metrics Detected | Dataset | Rule | Severity | Failure Rate | | :--- | :--- | :--- | :--- | | Patients | Null IDs | ❌ ERROR | 3.0% | | Visits | Orphan Records | ❌ ERROR | 8.5% | | Patients | Future Birth Dates | ⚠️ WARNING | 4.0% | ## 👨‍💻 Author **Vishnu Charan Kolla** [GitHub](https://github.com/vishnucharankolla2) | [LinkedIn](https://linkedin.com/in/vishnucharankolla2) <p align="center"><img src="https://capsule-render.vercel.app/api?type=waving&color=gradient&height=100&section=footer" width="100%"></p>
